# **Sonheim 개발 기록 (Development History)**

이 문서는 Sonheim 프로젝트의 2025년 3월부터 9월까지 월별 핵심 개발 내역을 기록합니다.

* **프로젝트 Repository:** https://github.com/chungheonLee0325/Sonheim  
* **개발 기간:** 25.03 - 25.04 (1개월 : 팀프로젝트) + 25.06 - 25.09 (4개월 : 개인프로젝트) 
* **플랫폼:** Unreal Engine 5 Multiplayer Game

## **개발 과정 요약 (Overview)**

* **(25.09) 프로젝트 안정화 및 문서화** : Wiki 시스템을 개편하고 인벤토리 시스템 안정화 및 주요 버그를 수정했습니다.  
* **(25.08) 게임플레이 시스템 확장** : 상자(Chest) 컨테이너와 제작(Crafting) 시스템을 완성하고 전투 시스템을 고도화했습니다.  
* **(25.07) 전투 경험 다양화** : 신규 무기 'Shotgun'을 추가하고 아이템 희귀도 시스템을 도입했으며, 피드백을 강화했습니다.  
* **(25.06) 아키텍처 리팩토링 및 성능 최적화** : 'Pal' 시스템을 컴포넌트로 분리하고 Object Pooling을 적용해 성능을 최적화했습니다.  
* **(25.04) 월드 탐험 및 콘텐츠 확장** : 'Glider' 이동 시스템을 도입하고 보스 몬스터 등 월드 콘텐츠를 추가했습니다.  
* **(25.03) 핵심 시스템 기반 구축** : Player, Inventory, Skill System 등 핵심 시스템의 기반과 네트워크 아키텍처를 확립했습니다.

## **Sonheim 월별 개발 기록 (Monthly Development History)**

### **2025년 9월**

프로젝트 안정화 단계에 접어들어, 종합적인 문서화 작업과 핵심 시스템의 안정성을 높이는 데 집중했습니다.

#### **핵심 업데이트**

* **Wiki 시스템 전면 개편:** Wiki 페이지 구조를 재설계하고 가이드 문서를 최신화했습니다.  
* **인벤토리 시스템 안정화:**  FastArray를 적용하여 인벤토리 관련 네트워크 트래픽을 최적화했습니다. 또한 Drag-and-drop 로직을 보강하고, 스킬 사용 중 무기 전환을 금지하는 등 안정성을 높였습니다.  
* **아이템 드롭 시스템 강화:** 몬스터 사망 시 아이템 드롭 규칙을 구체화하고 희귀도별 드롭률을 튜닝했습니다.  
* **주요 버그 수정:** UI 하이라이트 잔상, 특정 몬스터 사운드 미정지 이슈 등 다수의 버그를 해결했습니다.

#### **개발 영역**

| 시스템 구성요소 | 주요 변경사항                                                                 |
| :---- |:------------------------------------------------------------------------|
| **Documentation** | Wiki 페이지 재구성, README 업데이트, 기술 문서 개정                                     |
| **Inventory/Equipment** | FastArray적용, Drag & drop 로직 보강, Equip/Unequip 동기화 안정화, 스킬 사용 중 무기 전환 금지 |
| **Skills System** | Cost 메커니즘 확장 및 UI 반영                                                    |
| **Loot/Monster** | 몬스터 사망 시 아이템 드롭 시스템 구현, 드롭률 튜닝                                          |
| **Network Sync** | ForceNetUpdate/OnRep 핸들링 조정, 네트워크 동기화 경로 개선                             |
| **UI/UX** | 하이라이트 잔상 버그 수정, LambBall 포획 중 공격 사운드 미정지 이슈 수정                          |
| **Project Management** | 리소스/폴더 구조 정리, 미사용 에셋 정리                                                 |

### **2025년 8월**

주요 게임플레이 시스템을 구현하여 콘텐츠의 깊이를 더했습니다.

#### **핵심 업데이트**

* **상자(Chest) 컨테이너 시스템 구현:** 아이템 보관 상자 기능 및 멀티플레이 동기화 이슈를 해결했습니다.  
* **제작(Crafting) 시스템 완성:** 레시피 기반 아이템 제작 시스템과 전체 UI를 구현했습니다.  
* **'Pal Sphere' 포획 메커니즘 강화:** 포획 취소(RB), 조준 UI, 피드백을 개선하여 사용자 경험을 강화했습니다.  
* **전투 시스템 고도화:** 무기별 Crosshair, 이동 상태 기반 동적 탄 퍼짐(Spread), 반동(Recoil) 시스템을 도입했습니다.

#### **개발 영역**

| 시스템 구성요소 | 주요 변경사항 |
| :---- | :---- |
| **Container System** | Chest 구현, 재열람 시 동기화 이슈 해결 |
| **Crafting** | 제작 UI, 레시피 시스템, 재료 요구사항 구현 |
| **Capture Mechanics** | PalSphere 포획 취소(RB), 조준 UI 개선, 포획 피드백 강화 |
| **Weapon Systems** | 무기별 Crosshair, 이동 상태 기반 동적 탄 퍼짐 패턴, 근접 판정(Melee Trace) 안정화 |
| **Combat UX** | 반동(Recoil) 구현, 동적 탄 퍼짐 계산 로직 안정화 |
| **Project Management** | sync-source.yml 업데이트(머티리얼/에셋 경로 정리), 리소스/맵 정리 |

### **2025년 7월**

전투 경험을 다양화하고 사용자 피드백 시스템을 강화했습니다.

#### **핵심 업데이트**

* **네트워크 이펙트 최적화:** VFX/SFX 동기화 재생을 위한 Helper 시스템을 구축하여 부하를 최소화했습니다.

| 시스템 구성요소 | 주요 변경사항 |

| **Weapons** | Shotgun 구현 및 확산 패턴 로직 추가(전방 벡터 보정 등) |
| **Item System** | 아이템 희귀도(Rarity) 시스템 및 색상 코딩, 획득 팝업 알림 구현 |
| **UI/Feedback** | 몬스터 근접 시 툴팁/인디케이터, 공통 UI 가이드라인(HP/SP 바 위치 등) 정리 |
| **Player Stats** | 점프 높이/거리 스탯 튜닝 |
| **Network Effects** | 동기화된 이펙트 재생을 위한 VFX/SFX Helper 시스템 |
| **Code Quality** | 인벤토리/툴팁 관련 소규모 성능 및 가독성 리팩토링 |

### **2025년 3월**

프로젝트의 기술적 토대를 마련하고 핵심 게임플레이 루프를 확립했습니다.

#### **핵심 업데이트**

* **핵심 시스템 기반 구축:** Player, Inventory, Skill System 등 핵심 플레이어 시스템의 기반을 구현했습니다.  
* **데이터 드리븐 및 AI 아키텍처 설계:** 데이터 테이블 기반 구조와 몬스터 AI를 위한 FSM Base Class를 설계했습니다.  
* **'Pal Sphere' 핵심 메커니즘 구현:** Pal 포획(Capture), 소환(Summon), 교체(Swap) 기능의 프로토타입을 구현했습니다.  
* **네트워크 아키텍처 확립:** Steam/LAN 멀티플레이를 위한 Replication 설정 및 테스트 인프라를 구축했습니다.
